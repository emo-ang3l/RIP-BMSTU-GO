# Изменения в системе: Асинхронный расчет total_thickness

## Обзор изменений

Разделен код завершения заявки: расчет поля `total_thickness` перенесен в выделенный асинхронный Go-сервис.

## Новые компоненты

### 1. Go Calculation Service (`3LABRIP/GO/`)

**Описание**: Асинхронный сервис на Go для расчета `total_thickness` с задержкой 5-10 секунд.

**Основные файлы**:
- `main.go` - основной код сервиса
- `go.mod` - зависимости Go
- `Dockerfile` - образ для Docker

**Функциональность**:
- Принимает HTTP POST запросы на `/calculate`
- Выполняет расчет с задержкой 5-10 секунд
- Генерирует случайный результат (успех/неуспех, 70% вероятность успеха)
- Отправляет результат в Django через HTTP POST с токеном авторизации

**API**:
- `POST /calculate` - запуск расчета
- `GET /health` - проверка работоспособности

### 2. Изменения в Django Service

**Новый метод**: `update_thickness`
- Путь: `POST /api/insulatorrequests/{id}/update-thickness/`
- Принимает результаты от Go-сервиса
- Использует псевдо-авторизацию через токен "12345678" (8 байт)
- Обновляет поле `total_thickness` в заявке

**Измененный метод**: `complete`
- Убран синхронный расчет `total_thickness`
- Добавлен асинхронный вызов Go-сервиса через `threading.Thread`
- Заявка сохраняется без `total_thickness`, который будет рассчитан позже

**Новые зависимости**:
- `requests>=2.31.0` - для HTTP-запросов к Go-сервису

## Архитектура взаимодействия

1. **Клиент** → **Django**: Запрос на завершение заявки
2. **Django** → **База данных**: Обновление статуса и расчет `calculated_thickness` для деталей
3. **Django** → **Клиент**: Немедленный ответ (заявка завершена)
4. **Django** → **Go-сервис** (асинхронно): Запрос на расчет `total_thickness`
5. **Go-сервис**: Выполнение расчета с задержкой 5-10 секунд
6. **Go-сервис** → **Django**: Отправка результата с токеном
7. **Django** → **База данных**: Обновление `total_thickness`

## Конфигурация

### Docker Compose

Добавлен новый сервис `go-service`:
- Порт: 8080
- Сеть: insulation-network
- Переменные окружения:
  - `DJANGO_URL=http://django:8000`

### Django Settings

Добавлена переменная окружения:
- `GO_SERVICE_URL=http://go-service:8080` (по умолчанию)

## Безопасность

- Псевдо-авторизация через токен "12345678" (8 байт)
- Метод `update_thickness` доступен без стандартной аутентификации Django
- Проверка токена выполняется в методе перед обновлением данных

## Тестирование

Для тестирования системы:

1. Запустить все сервисы через `docker-compose up`
2. Создать и сформировать заявку
3. Завершить заявку через API
4. Проверить, что заявка получила статус COMPLETED сразу
5. Подождать 5-10 секунд и проверить, что `total_thickness` обновился
